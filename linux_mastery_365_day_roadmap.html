How to use this roadmap

  1. Read the topic and open the learning link.
  2. Run commands in a Linux terminal or browser lab. A restricted simulator may not support every command.
  3. Complete the task without copying a solution.
  4. Tick the checkbox only when you can explain what you did.
  5. Keep a notes file with the command, its purpose, an example, and what happened.
Safety: Practise destructive commands, permission changes, firewall rules, and service changes only in your own test environment. Never run a command with sudo unless you understand its effect. Don't expose a test server to the public internet without learning how to secure it.
