A 365-day pathway from core security concepts through OS and network foundations, defensive monitoring, web application security, safe vulnerability assessment, scripting, incident response, cloud security, architecture, and portfolio capstones. It supports multiple career directions; true expertise requires continued hands-on work beyond this calendar.

How to use this: plan for 60–180 minutes most days. Read, practise in your own lab, write down results, explain concepts in your own words, and review mistakes. The later phases deepen and integrate skills; a roadmap is a guide, not a guarantee of expert status. Test only systems you own or have explicit permission to assess.
